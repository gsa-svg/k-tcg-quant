Set notes — price context, reprints, factory-seal check, background

Buggy on top, and the run starts quoting itself

The Azure Sea's Seven produced the fandom's favorite market fact: Buggy — the clown — leads the chase table, in gold-stamped and standard SP forms. Behind the joke is a structural shift worth noticing: much of this set's top ten consists of stamped reprints of older hits, cards carrying OP-09 and PRB-02 numbers. The run has started quoting its own back catalogue.

Stamped reprints behave differently from originals — they add supply to a character while remaining distinct collectibles, and their prices key off the original printing. A box this recent is still settling, so treat the live table above as the current read rather than a settled ranking.

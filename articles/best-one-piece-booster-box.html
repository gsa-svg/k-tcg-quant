No single number identifies the best sealed box. This guide explains how OP Box Index compares completed sales, active listings, chase-card concentration, grading data and listing quality. The same inputs appear on the comparison table, with their limits stated below.

Rule 1: separate completed sales from asking prices

A completed sale records a transaction; an active listing records the seller's current ask. Compare the median and sample size of recent matched sales with the lowest verified listing, including shipping. OP Box Index labels listing-based values as ask so the two sources are not mixed.

Rule 2: measure visible chase-card support

Card support compares the tracked value of a set's top chase cards with its box price. It shows the size and breadth of the visible chase market, but it is not opening expected value because official pull rates are unpublished.

Rule 3: beware the one-card box

If one manga rare makes up more than half of the tracked top-10 value, the set receives a top-heavy label. This describes concentration only. It does not estimate the probability of pulling that card or the return from opening a box.

Rule 4: read listing depth and completed sales together

Active-listing count describes visible availability on the marketplaces checked; completed-sale count describes observed transactions during the sample window. Neither is total supply or total demand. A useful comparison states the date, sample size and exact language edition for both.

Rule 5: pull rates are not public — respect that

Bandai does not publish official pull rates for the One Piece Card Game, and community estimates vary between print waves. A precise opening expected value therefore depends on unofficial rate assumptions and should not be presented as a manufacturer-confirmed figure. We publish the box price, completed chase-card prices and value concentration, while leaving the missing pull-rate input explicit.

Putting it together

Start with four checks: Is the price based on matched completed sales or an ask? Is visible chase value spread across several cards? How deep are the listing and sale samples? Can the seller and original seal be verified (see the reseal checklist)? The comparison table updates these signals from eBay data, and each set page shows the underlying price band, chase list and PSA context.

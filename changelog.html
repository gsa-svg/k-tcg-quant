Transparency

Data corrections & change history

When a number on this site turns out to be wrong, it gets fixed and recorded here — date, what was wrong, and what changed. Automated collection also breaks sometimes; outages that affected published data are listed too. Entries below are drawn from the project's actual commit history. Found something wrong that isn't listed? Email gsa@whatsong.kr.

  • 2026-08-27

    OutageThe daily eBay listings pipeline had been silently stopped for 3 days (a set with zero qualifying listings was mistakenly treated as a fatal error). Fixed, and the missed collection was re-run the same day. Listing-based figures dated 2026-08-24 to 2026-08-26 were delayed, not wrong.

  • 2026-08-26

    CorrectionFour card-data errors corrected across the grading collectors, and TAG name validation was loosened where it had been wrongly rejecting valid matches (tracked TAG cards went from 185 to 196).

  • 2026-08-26

    OutageThe market-data workflow file had a formatting error that stopped automated runs. Repaired, and a workflow audit was added so the same failure cannot pass unnoticed again.

  • 2026-08-25

    CorrectionThree grading-population misattributions were found and corrected (cards credited to the wrong set or variant). An independent attribution audit now re-verifies every card against the grader's own label on each run.

  • 2026-08-24

    CorrectionThe auction page was publishing the current day's still-open auctions as if they were final results. Now only completed days are published.

  • 2026-08-21

    CorrectionThree CGC cards were missing from collection due to a blind spot in the collector. Backfilled.

  • 2026-08-17

    CorrectionThe exchange rate used for currency conversion had been frozen for 47 days. Corrected, and the Monday grading collection that had stalled was restored.

  • 2026-08-12

    CopyRemoved a causal overclaim from set panels: grading counts measure grading submissions, not box openings. The site no longer implies one proves the other.

  • 2026-08-12

    PolicyAffiliate disclosure moved above the fold on every page with eBay links, following an eBay Partner Network compliance notice.

  • 2026-07-30

    CorrectionPRB-01 Nami was showing OP-01's manga art instead of THE BEST's, and OP-09 Gol D. Roger carried a wrong card number (caught via a CGC population screenshot). Both fixed.

  • 2026-07-29

    CorrectionA wrong date label appeared on every set's weekly grader-change figure. Fixed, and the underlying numbers were re-audited.

  • 2026-07-28

    CorrectionFive card prices were wrong due to variant mix-ups in matching (a different printing's price was being picked up). Corrected, with new guards to block recurrence. Separately, CGC collection had been missing 9 of 43 list pages due to a pagination bug — backfilled.

  • 2026-07-28

    CorrectionEmpty English-edition cells had been labeled "unreleased" even where the English printing exists. Blank now means "no data", never a claim about the product.

Routine daily data refreshes are not listed — only corrections, outages and policy changes. See methodology for how the data is collected, and about for who runs this site.
